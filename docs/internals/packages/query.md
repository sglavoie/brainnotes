# internal/query

[Back to the architecture map](../architecture.md).

- `internal/query` — composable `Predicate` functions over `*vault.Note` for the `find` command's frontmatter dimensions (tag/category/status/type/has/missing/folder/age/orphan), plus the path-aware wikilink graph reused by recall ranking. `And` is the identity-with-no-args combinator; queries with no flags match everything. The graph contract is no longer only orphan detection: `graph_metrics.go` derives `GraphMetrics` from a built `Graph` by inverting `Forward` into sorted out/in/both adjacency, and answers **bounded graph traversal** — `Degree` (the *undirected* distinct-neighbour count), undirected connected `Components`/`ComponentSize`, and `Distances`/`Distance` BFS under a `maxHops` bound where a negative bound means unbounded, plus `ShortestPath`, which computes distances *towards* the target and steps greedily to the smallest neighbour one closer, yielding the lexicographically smallest shortest path without enumerating paths. `filter_graph_ops.go` turns that into the six graph predicates `queryexpr` lowers onto (`LinksTo`, `LinkedFrom`, `Near`, `PathTo`, `Degree`, `ClusterSize`), each of which resolves its target **once at build time** into a key set or a reachable set, so a term costs one traversal per scan rather than one per note. Direction on `Near`/`PathTo` is anchored at the **candidate note**, not the target: `DirOut` means "the note reaches the target by its own outgoing links", implemented as one BFS out of the target along `dir.reverse()`. Every one of them ends in `Reachable(g, keys)`, the exported membership test, which is why the memoized `queryexpr` path runs literally these predicates rather than a reimplementation. Two keyspaces coexist and must not be confused: `GraphMetrics` takes a **note key** (`areas/foo`), while `Graph.OutDegree`/`InDegree` take a **title** — resolve through `Graph.KeyForNote` or `Graph.ResolveTarget` first. An isolated note is a component of size 1 with degree 0, so `cluster-size:1` and `degree=0` both mean "unlinked note"; membership is gated on `GraphMetrics.has` so a note absent from the graph never matches at all.
