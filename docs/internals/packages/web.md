# internal/web

[Back to the architecture map](../architecture.md).

- `internal/web` — the HTTP server, its page handlers, and its mutating APIs. Its one cross-cutting invariant is the **serving-mode capability table** in `capabilities.go`: `NewServer` derives a `Mode` (`local`, `read-only`, `hosted`) once from `Options` and everything downstream asks `s.caps` rather than re-deriving a deployment from a flag. The capabilities are independent dimensions — `documentWrites`, `processLaunch`, `browserOpen`, `maxRequestBody` — precisely so hosted cannot be implemented as "read-only with writes turned back on": a hosted vault writes notes and never starts a *configured* command, while a replica does neither and still navigates on Open. `requestGuard` is the single middleware that publishes the private caching and sniffing headers, applies the read-only allowlist and the process-launch route refusal, rejects a cross-origin state change, and bounds the body — all before a handler runs — and `openPath`/`launchAgent` refuse again at the only two places a *request* can reach a **configured** command, so the guarantee does not depend on a route list staying complete. (`browser.go` builds a third `exec.Cmd`, for the startup browser launch that no route reaches; its caller checks the same capability. A fourth is reachable from a request and is deliberately not gated: a journaled mutation forks `git` through `internal/vaultgit`, which is what makes a hosted write recoverable, and it runs an executable resolved once at `Open`, with no shell and with every argv built by the engine. Note *paths* do reach that argv, at four call sites, and each is safe for a reason of its own rather than by exclusion: `ls-tree` and `ls-files` take them as pathspecs after `--`, where `GIT_LITERAL_PATHSPECS` also makes a name containing glob characters select itself; `hash-object` takes one as a file operand after `--`; and `update-index --cacheinfo` takes one as the last of three operands that option consumes positionally. None of the four can be read as an option. Note *bytes*, config keys and request fields reach no argv at all.) Contract in `docs/internals/serving-modes.md`; the write classes a mutation must then satisfy are in `docs/internals/web-write-classes.md`.
