# internal/web/static_src

[Back to the architecture map](../architecture.md).

- `internal/web/static_src` — strict TypeScript source for first-party browser behavior. `esbuild` bundles it into `internal/web/static/app.js`, which stays committed so Go builds and installs do not require Node. `internal/web/static/cytoscape.min.js` remains vendored and is not bundled, and neither is the **vendored layout chain** it anchors — `layout-base.min.js` → `cose-base.min.js` → `cytoscape-fcose.min.js`, whose `<script>` order in `templates/graph.html` is load-bearing because fcose is built on cose-base on layout-base and must be registered against the global Cytoscape factory before `app.js` runs; the controller degrades to `cose` when that registration did not happen. **CodeMirror goes the other way and is bundled rather than vendored**, and the contrast is the reason rather than an inconsistency: the six `@codemirror/*` packages the raw-Markdown editor needs are ES modules that assume a resolver and publish no global-factory build to register against, which is the one property that makes Cytoscape's chain vendorable. The price is visible in the artifact — `app.js` went from 537 KB to 1.6 MB and esbuild now warns about the size on every build — and it is paid by a page the browser caches, once. All of that third-party surface is reachable from exactly one module, `static_src/source-editor-view.ts`, which is a CodeMirror adapter behind the `SourceSurface` interface and holds no editor behaviour of its own; everything the editor *decides* sits in modules a fake surface can drive under jsdom. The `/graph` page's three display knobs (isolate, minimum degree, folder collapse) are a **client-side display pipeline** over the already-fetched payload (`static_src/graph-controller-view.ts`), never a server concern: `internal/web/graph.go` stays a faithful directed graph. Isolation is fixed at one undirected hop and owns no radius option — the retired `g_hops` parameter is deleted from a legacy URL by the page itself, which is the entire compatibility story and touches no route. Because the bundle is the artifact the browser loads, a `static_src/` change is only complete once `app.js` is regenerated (`just web-build`, or `just web-check`/`just ci`, which rebuilds and byte-compares to catch drift). `docs/internals/graph-view.md` holds that contract.
